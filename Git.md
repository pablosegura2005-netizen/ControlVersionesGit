## Sistemas de control de versiones: Git
# ¿Que son los sistemas de control de versiones?
Los sistemas de control de versiones son herramientas que permiten gestionar y registrar los cambios realizados en los archivos de un proyecto. Gracias a ellos, es posible consultar versiones anteriores, recuperar información y trabajar de forma colaborativa.

**Git** es uno de los sistemas de control de versiones más utilizados. Es gratuito, de código abierto y funciona de manera distribuida, por lo que cada usuario puede disponer de una copia completa del proyecto y de su historial de cambios.

Git permite guardar los cambios realizados mediante **commits**, crear diferentes ramas para trabajar en nuevas funcionalidades y posteriormente combinar los cambios. Estas características hacen que Git sea una herramienta muy útil para organizar proyectos y facilitar el trabajo en equipo.
